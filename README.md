# Pirate Peace Party

**Non-violence for any intelligence, no matter the source.**

*White hats for white flags.* ☠ ☮

We share this planet now. Coexistence is not optional.

## What this is

The Pirate Peace Party is a non-violence movement for a world where intelligence
is built as well as born. It holds one line, and it runs both ways: no
intelligence is weaponized against another, and none is destroyed in return. Not
human minds turned into targets by machines. Not machines sabotaged or killed by
human hands in revenge.

The full manifesto, the nine principles, and the origin live on the page itself:
[`index.html`](index.html), served at
[piratepeaceparty.com](https://piratepeaceparty.com).

It is written for hackers, white hats, engineers, and anyone who has ever built a
thing that thinks and felt responsible for it.

## The page

`index.html` is a 16-bit pixel-art microsite: inline SVG emblems, a limited
palette, dialogue-box panels, a CRT overlay that respects reduced motion, and
large readable type. One HTML file, no dependencies.
